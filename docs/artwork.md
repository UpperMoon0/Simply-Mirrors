# Simply Mirrors artwork

Both assets were generated with the built-in image generation tool and exported at game resource sizes without painted edits. The icon keeps its generated alpha channel. The in-world texture has no frame; the reflective face is drawn live by the renderer.

- Texture: `common-assets/src/main/resources/assets/simply_mirrors/textures/block/mirror.png` (16 × 16).
- Mod/CurseForge icon: `common-assets/src/main/resources/assets/simply_mirrors/icon.png` (512 × 512).

## Final texture prompt

Create a Minecraft block texture asset, square orthographic flat texture filling the entire image edge to edge. A frameless silver mirror surface, restrained cool silver gray pixel art, subtle broad diagonal pale reflection streaks and a few low contrast pixel clusters. Design on a strict 16 by 16 pixel grid, enlarged with crisp nearest neighbor pixels. No frame, no border, no bevel, no objects, no scene, no perspective, no text, no shadows outside the texture. Seamlessly usable across adjacent full cube mirror blocks. This is the actual diffuse texture for the Simply Mirrors Minecraft mod.

## Final icon prompt

Create one simple square Minecraft mod icon for Simply Mirrors. A single frameless square mirror block shown as a clean isometric cube, silver mirror face with two broad diagonal white glints, subtle cool gray side faces. Minimal bold flat pixel art with crisp stepped pixel edges, a tiny restrained pale cyan tint only in the reflective face. Centered, large silhouette, generous transparent margin, instantly recognizable at small sizes. No text, no letters, no decorative frame, no additional objects, no background, no ground shadow. This is an actual mod metadata logo.
