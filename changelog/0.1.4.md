# Simply Mirrors 0.1.4

## Performance

- Fix a major GPU frame-rate regression when using Complementary, Iris, or Oculus with planar mirrors. Reflected shader rendering now limits fragment work to a conservatively padded, full-resolution region covering the visible mirror plane, rather than shading the entire screen for a small mirror.
- Preserve original reflection texture resolution, full-screen shader initialization, the shadow map, temporal history restoration, and unchanged mirror clipping. Mirrors near the near plane or covering most of the viewport automatically fall back to the uncropped render path.
- Retain a bounded GPU renderbuffer pool for Iris/Oculus history snapshots, reducing repeated memory allocations.
- Preserve coplanar mirror batching and reduce redundant geometry work.

## Verification

On a real GTX 1050 Ti with Forge 1.20.1, Oculus 1.8.0, Embeddium 0.3.31, and Complementary Reimagined r5.9.3 HIGH at 1280×720:

- One mirror: **75.97 → 115.85 FPS (+52.5%)**.
- Nine coplanar mirrors: **75.02 → 99.35 FPS (+32.4%)**.
- No-mirror performance remained essentially unchanged.

The comparison used the same renderer revision with projected coverage on/off in an isolated in-game client, not a synthetic OpenGL compositor benchmark. An enclosed-room shader acceptance test passed all six mirror-face orientations on the NVIDIA GPU; shared reflection tests passed 62/62. These GPU results are host/scene-specific and do not guarantee the same gain in every world or shader pack.

The optimization can be disabled for troubleshooting with the Java system property `-Dsimplymirrors.coverageScissor=false`.

## Support

Minecraft 1.16.5, 1.20.1, 1.21.1, and 26.1.2, on the existing Fabric, Forge, and NeoForge targets. Shader packs remain optional.
