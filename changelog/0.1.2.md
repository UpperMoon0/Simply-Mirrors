# Simply Mirrors 0.1.2 (unreleased)

- Repair incomplete Iris reflection gbuffers when a mirror's depth-only texture
  conflicts with a separate packed stencil attachment; restore the original
  stencil and framebuffer bindings after rendering.
- Hook optional Iris framebuffer bind/depth-attachment transitions on Minecraft
  1.21.1, before a reflection draw or read can encounter an unsupported FBO.
- Expand native OpenGL regression coverage for split depth/stencil repair and
  scoped restoration, preserving complete main-camera framebuffers.
- Preserve the existing shader acceptance across supported loaders and versions,
  including the pinned Iris/Sodium/Complementary/Euphoria rendering combination.
- Restore the original stencil attachment topology for single-layer array/3D
  textures and cube faces; cover array layers zero and one with native GL tests.

### Production incident and verification

ATM10 To the Sky 2.3.1 reproduced sky/cloud-only reflections across all six
orientations with Complementary, both with and without Euphoria Patcher,
while non-shader reflections worked. A reflected Iris framebuffer combined
the mirror's depth-only texture with a separate packed depth/stencil
attachment, producing `GL_FRAMEBUFFER_UNSUPPORTED` (36061) and
`GL_INVALID_FRAMEBUFFER_OPERATION` (1286). The
[production full-pack diagnostic](https://github.com/UpperMoon0/Simply-Mirrors/actions/runs/41315896303)
subsequently passed all three shader modes. Permanent CI pins the relevant
rendering components rather than installing the entire modpack. Software GL
acceptance does not guarantee every physical GPU driver.

Release gate: all checks on the final, modpack-independent CI head must
pass, including the targeted stencil and reflected-player motion regressions.
Do not publish this development build until release review is complete.
