# Simply Mirrors 0.1.0

- Add craftable frameless mirror blocks with live reflections on all six faces, including floors and ceilings.
- Add a Simply Mirrors creative tab, custom mirror texture, and mod icon.
- Support Fabric/Forge 1.16.5 and 1.20.1, plus Fabric/NeoForge 1.21.1 and 26.1.2.
- Merge coplanar reflections and hide internal faces between adjacent mirror blocks.
- Fix angled-view freezes in vanilla camera-frustum fitting.
- Use MIT as the project license; preserve the included Apache-2.0 notices for CE-derived portions.
- Publish verified builds for all eight targets to GitHub and CurseForge as Release files.
